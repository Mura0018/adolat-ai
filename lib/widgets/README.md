# widgets/

Ilovaning dizayn-tizimi (design system) — bir nechta feature bo'ylab qayta ishlatiladigan umumiy UI komponentlar: tugmalar, matn kiritish maydonlari, yuklanish indikatorlari, xatolik/bo'sh holat widgetlari.

Muayyan feature'ga xos, boshqa joyda ishlatilmaydigan widgetlar bu yerda emas, tegishli `features/<nom>/presentation/widgets/` ichida joylashadi.
