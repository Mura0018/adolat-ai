# shared/validators/

Bir nechta feature bo'ylab ishlatiladigan, biznesga xos bo'lmagan umumiy forma validatsiya qoidalari: masalan email formati, telefon raqami formati, minimal/maksimal uzunlik tekshiruvi.

Muayyan feature'ga xos validatsiya qoidalari (masalan, "murojaat matni kamida N ta so'z bo'lishi kerak") tegishli `features/<nom>/` ichida qoladi.
