# theme/

Ilovaning vizual identifikatsiyasi: ranglar, tipografiya va shulardan yig'ilgan `ThemeData` (light/dark).

| Fayl | Vazifasi |
|---|---|
| `app_colors.dart` | Rang palitrasi konstantalari |
| `app_typography.dart` | Matn uslublari (`TextTheme`) |
| `app_theme.dart` | `AppColors` va `AppTypography`dan yig'ilgan yakuniy `ThemeData` (light/dark) |
