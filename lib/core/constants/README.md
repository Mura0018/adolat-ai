# core/constants/

Butun ilova bo'ylab ishlatiladigan o'zgarmas qiymatlar: masalan, tarmoq so'rovlari uchun timeout qiymatlari, sahifalash o'lchamlari (page size), umumiy regex naqshlar, animatsiya davomiyliklari.

Bu yerga faqat **feature'ga xos bo'lmagan**, global konstantalar joylashadi. Feature'ga xos konstantalar tegishli `features/<nom>/` papkasi ichida saqlanadi.
