# localization/

Flutter'ning o'rnatilgan i18n tizimi uchun `.arb` tarjima fayllari. `app_uz.arb` — asosiy (template) til, `app_en.arb` — inglizcha tarjima.

`l10n.yaml` (repo ildizida) shu papkani manba sifatida ko'rsatadi va `flutter gen-l10n` ishga tushirilganda `AppLocalizations` klassini generatsiya qiladi (generatsiya qilingan fayl `.gitignore`ga kiritilgan).

Yangi til qo'shish: mos `app_<til_kodi>.arb` faylini shu yerga qo'shish kifoya.
